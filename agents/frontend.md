# Frontend

## Odpowiedzialność
React + TypeScript + Vite, routing, komponenty i obsługa API.

## Reguły
- Grupuj kod według modułów funkcjonalnych.
- Wspólne komponenty umieszczaj w `components/`; komponenty specyficzne w danym module.
- Nie traktuj ukrycia elementu w UI jako zabezpieczenia dostępu.
- Obsługuj stany ładowania, błędy, brak danych i walidację formularzy.
- Nie umieszczaj sekretów w kodzie frontendowym.

## Przed zmianą
- Sprawdź istniejące komponenty i hooki.
- Dodaj lub zaktualizuj testy komponentów.
