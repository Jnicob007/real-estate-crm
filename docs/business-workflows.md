# Przepływy biznesowe

1. Klient wysyła formularz na stronie.
2. API waliduje i zapisuje zgłoszenie.
3. Administrator otrzymuje powiadomienie lub tworzy zgłoszenie na podstawie e-maila.
4. Administrator przekazuje zgłoszenie kierownikowi.
5. Kierownik przydziela zadania agentom i ustawia terminy.
6. Agent aktualizuje statusy i oznacza zadanie jako wykonane.
