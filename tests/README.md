# Testy

Umieszczaj testy integracyjne, end-to-end, fixtures i pomocnicze narzędzia w odpowiednich podkatalogach. Testy uprawnień i izolacji danych są obowiązkowe dla chronionych endpointów.

Testy rejestracji i sesji API: `npm test --workspace server` (`user.service.test.ts`, `auth.service.test.ts`, `auth.http.test.ts`).
