# Baza danych

Docelowa baza: MySQL. Schemat należy rozwijać przez migracje w `migrations/`.

Planowane encje: users, employees, leads, tasks, task_history, lead_history, notifications, audit_logs, email_messages oraz sessions (jeśli zostanie wybrana autoryzacja sesyjna).

Przed wdrożeniem ustal dokładny schemat, klucze obce, indeksy, retencję danych i strategię kopii zapasowych.
